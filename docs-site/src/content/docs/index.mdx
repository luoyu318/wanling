## 万灵小程序是什么

万灵小程序是运行在万灵 APP 内的轻量级 H5 应用容器。使用纯静态前端技术栈（HTML/CSS/JS）即可开发，无需任何原生开发环境。小程序通过平台分发到聊天与会话场景，借助分享卡片在用户之间传播。

## 能力总览

| 能力 | 说明 |
| --- | --- |
| 调用万灵 API | 经 `wanling.request` 以登录态代理访问平台 `/api/` 接口 |
| 身份标识 openid | 获取同一用户在你小程序内唯一且永久稳定的标识 |
| 会话上下文读取 | 从聊天卡片打开时读取来源会话 ID，实现会话内联动 |
| 分享卡片到会话 | 将小程序卡片发送到用户选择的好友或群聊 |
| 跳转宿主页面 | 在白名单内跳转到宿主原生页面（如小程序列表） |
| 宿主资源直引 | 包内页面可直接以相对路径引用当前用户可见的宿主图片资源（如头像） |

以上能力的调用方式详见 [JSBridge 参考](/docs/api/bridge/)。

## 工作原理

- **包**：开发者将静态页面打成 zip 上传，由 `manifest.json` 声明元信息与所需权限。详见[包格式规范](/docs/guides/manifest/)。
- **容器**：小程序页面运行在 APP 内 WebView 的独立虚拟 origin 中，登录凭证永不进入 JS 环境，所有平台 API 调用经原生层代理转发。
- **分发**：新上传的小程序为私有状态，仅自己可见可运行；经管理员发布后进入公共库，全员可见；已发布的小程序可通过聊天卡片分享传播。

## 适合谁

懂 HTML/JS 的前端开发者即可上手。不需要 Android/iOS 开发环境，一个编辑器加一条打包命令，就能从零构建并运行你的第一个小程序。准备好了就从[快速开始](/docs/quickstart/)出发。
